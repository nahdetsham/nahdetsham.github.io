# موقع شركة نهضة شام

الموقع الرسمي لشركة نهضة شام بالعربي والإنكليزي: https://nahdetsham.github.io

## تعديل النصوص
كل نصوص الموقع موجودة بـ `content/`:
- `ar.json` فيه النصوص العربية، و`en.json` فيه نفس النصوص بالإنكليزي.
  - لازم يكون الملفين فيهن نفس المفاتيح، وإلا البناء بيوقف وبيقلّك شو الناقص.
- `shared.json` فيه الشغلات يلي ما بتتغيّر مع اللغة:
  - رقم الواتساب، والإيميل، ورابط استمارة التسجيل، والحسابات.
  - الدورات، وقوائم يوتيوب، وموقع المؤسس.
- **الفريق:** `team` بـ `shared.json`. لما ينضاف فيه أسماء، قسم الفريق بيبيّن بصفحة «عن الشركة».

## التشغيل على الجهاز
```bash
npm install
npm run build
node tools/serve.mjs out 4100
```
بعدين افتح http://localhost:4100/ar/

## النشر
كل ما ينرفع شي على `main`، GitHub Actions (`.github/workflows/deploy.yml`) بيبني الموقع وبينشره لحالو على GitHub Pages.

## الأدوات (`tools/`)
| الأداة | شو بتعمل |
|---|---|
| `extract_logo.py` | بتطلّع الشعار كـ SVG من ملف الـ Illustrator، مع نقطة الضاد من `panner_2.ai` |
| `wordmark.py` | بترسم اسم الشركة بخط DG Heaven كـ SVG |
| `make_icon.py` | بتعمل أيقونة الموقع |
| `media.py` | بتضغط الفيديوهات والصور للويب، وبتحطها بـ `public/media` |
| `og.js` | بتعمل صور المشاركة بالعربي والإنكليزي، و`logo-512.png` |
| `check_links.mjs` | بتفحص كل الروابط (ضيف `--external` لتفحص الروابط الخارجية كمان) |
| `postbuild.mjs` | بتطلّع صفحة 404 وملف `.nojekyll` بعد البناء |

## التقنية
- **Next.js 15** بتصدير ثابت (`output: "export"`).
- **GSAP 3** مع ScrollTrigger و DrawSVG.
- **Lenis** للنزول الناعم بالصفحة.
- **الخطوط:** Samim محلي، وDG Heaven للاسم بس.
- **تقليل الحركة:** إذا الزائر مفعّل `prefers-reduced-motion`، بيطلعله الموقع كامل وثابت بلا حركة.
